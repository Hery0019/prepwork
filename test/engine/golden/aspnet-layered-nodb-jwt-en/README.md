# edge-api

Stateless edge API

ASP.NET Core project generated by prepwork 0.1.0. Conventions for the agent live in `CLAUDE.md` and `.claude/skills/`; this README is for humans and belongs to the team.

## Prerequisites

- .NET SDK 10.0.400 or newer in the same band (see `global.json`)
- gitleaks: the `pre-commit` hook rejects every commit until it is installed (https://github.com/gitleaks/gitleaks#installing)

## Getting started

```sh
cp .env.example .env            # then adjust the values
git config core.hooksPath .githooks
dotnet test                     # compiles, the three levels, the architecture rules
dotnet run --project src/Edge.Api.Api
```

The API is exposed under `/api/v1/`; `GET /health` answers as soon as the application starts and `GET /openapi/v1.json` serves the OpenAPI document in development.

Without Docker: `dotnet test --filter Category!=Integration` runs the whole suite that needs no container.

## Structure

| `src/Edge.Api.Application/` | The `application` project |
| `src/Edge.Api.Infrastructure/` | The `infrastructure` project |
| `src/Edge.Api.Api/` | The `api` project |
| `tests/Edge.Api.Tests/` | The `tests` project |

## Updating generated files

Edit `scaffold.yaml`, then run `prepwork sync`. A generated file the team has modified is reported, never overwritten.
