# ADR 0006 — Continuous integration

Date : 2026-09-03 · Status : accepted

## Context

Choice made in the prepwork questionnaire. CI runs `dotnet test` (the three levels, architecture rules) and `dotnet format --verify-no-changes` and the NuGet audit (CORE-035).

## Decision

**No CI generated** for now; checks stay local (`dotnet test`).

## Consequences

A red build blocks the merge; CI does nothing that `dotnet test` does not already do locally.
