# Décisions d'architecture (ADR)

Une décision par fichier, numérotée, jamais réécrite : une décision remplacée reçoit le statut « remplacée par ADR-NNNN » et la nouvelle décision est un nouveau fichier. Les sept premières ADR ont été créées par prepwork à partir des réponses au questionnaire ; ce répertoire appartient à l'équipe.

## Format

```markdown
# ADR NNNN — Titre

Date : YYYY-MM-DD · Statut : proposée | acceptée | remplacée par ADR-NNNN

## Contexte
## Décision
## Conséquences
```

L'agent propose une ADR avant de coder toute décision qui change l'architecture (CORE-001, CORE-006) ; un humain l'accepte.
