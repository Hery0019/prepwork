# shop-api

Shop API

Spring Boot project generated by prepwork 0.1.0. Conventions for the agent live in `CLAUDE.md` and `.claude/skills/`; this README is for humans and belongs to the team.

## Prerequisites

- JDK 21
- Docker (Testcontainers for slice and integration tests)
- Maven ships with the wrapper (`./mvnw`, `mvnw.cmd`)
- gitleaks: the `pre-commit` hook rejects every commit until it is installed (https://github.com/gitleaks/gitleaks#installing)

## Getting started

```sh
cp .env.example .env            # then adjust the values
git config core.hooksPath .githooks
./mvnw verify                   # compile, tests, ArchUnit rules
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

The API is exposed under `/api/v1/`; `GET /actuator/health` answers as soon as the application starts.

## Structure

| Path | Purpose |
|---|---|
| `scaffold.yaml` | Project choices; the only input of `prepwork sync` and `prepwork check` |
| `CLAUDE.md`, `.claude/skills/` | Conventions for the agent (generated) |
| `docs/adr/` | Architecture decision records (team-owned) |
| `docs/glossary.md` | Business vocabulary (team-owned) |
| `.scaffold/manifest.json` | List of generated files and their hashes |
| `src/` | Skeleton of the `layered` profile, reference example and tests |

## Updating generated files

Edit `scaffold.yaml`, then run `prepwork sync`. A generated file the team has modified is reported, never overwritten.
