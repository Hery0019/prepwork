# ADR 0006 — Continuous integration

Date : 2026-09-02 · Status : accepted

## Context

Choice made in the prepwork questionnaire. CI runs `./mvnw verify` (three test levels, ArchUnit rules, formatting) and the vulnerable dependency scan (CORE-035).

## Decision

**GitLab CI**: pipeline on every push and merge request, Docker available for Testcontainers.

## Consequences

A red build blocks the merge; CI does nothing that `./mvnw verify` does not already do locally.
