# Architecture decision records (ADR)

One decision per file, numbered, never rewritten: a superseded decision gets the status "superseded by ADR-NNNN" and the new decision is a new file. The first seven ADRs were created by prepwork from the questionnaire answers; this directory belongs to the team.

## Format

```markdown
# ADR NNNN — Title

Date : YYYY-MM-DD · Status : proposed | accepted | superseded by ADR-NNNN

## Context
## Decision
## Consequences
```

The agent proposes an ADR before coding any decision that changes the architecture (CORE-001, CORE-006); a human accepts it.
