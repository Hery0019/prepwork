# ADR 0007 — Languages

Date : 2026-09-02 · Status : accepted

## Context

Code identifiers are always in English (CORE-040, non-negotiable). Only the languages of comments and documentation are a team choice.

## Decision

- Comments : **English**
- Documentation : **English**

## Consequences

Business terms are defined in `docs/glossary.md` in the English form used in the code (CORE-042).
