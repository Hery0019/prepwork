# ADR 0007 — Langues

Date : 2026-09-02 · Statut : acceptée

## Contexte

Les identifiants du code sont toujours en anglais (CORE-040, non négociable). Seules les langues des commentaires et de la documentation sont un choix d'équipe.

## Décision

- Commentaires : **français**
- Documentation : **français**

## Conséquences

Les termes métier sont définis dans `docs/glossary.md` sous leur forme anglaise utilisée dans le code (CORE-042).
