# ADR 0006 — Langues

Date : 2026-09-03 · Statut : accepté

## Décision

- Identifiants du code : anglais, toujours
- Commentaires : fr
- Documentation : fr
- Interface : traduite (i18next)

## Conséquences

Le texte affiché passe par t() même sans i18n : activer les traductions plus tard reste mécanique.
