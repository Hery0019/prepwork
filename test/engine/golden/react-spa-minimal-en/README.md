# kiosk

Read-only dashboard

React application generated by prepwork 0.1.0. Conventions for the agent live in `CLAUDE.md` and `.claude/skills/`; this README is for humans and belongs to the team.

## Prerequisites

- Node 22 and pnpm (`corepack enable pnpm`)
- gitleaks: the `pre-commit` hook rejects every commit until it is installed (https://github.com/gitleaks/gitleaks#installing)

## Getting started

```sh
cp .env.example .env
git config core.hooksPath .githooks
pnpm install
pnpm dev
```

Commit `pnpm-lock.yaml` right after the first install: the versions are pinned in `package.json`, and CI installs in frozen mode (`--frozen-lockfile`).

## Commands

| Command | What it does |
|---|---|
| `pnpm build` | `tsc --noEmit && vite build` |
| `pnpm dev` | `vite` |
| `pnpm format` | `prettier --write .` |
| `pnpm lint` | `eslint . && stylelint "src/**/*.css" && depcruise src` |
| `pnpm preview` | `vite preview` |
| `pnpm test` | `vitest run` |
| `pnpm typecheck` | `tsc --noEmit` |

## Structure

| Path | Purpose |
|---|---|
| `src/app` | layer `app` — depends on features, entities, shared |
| `src/features/*` | layer `features` — depends on entities, shared |
| `src/entities/*` | layer `entities` — depends on shared |
| `src/shared` | layer `shared` — depends on nothing |
| `src/shared/styles/tokens.css` | Visual contract, generated from the preset |
| `src/shared/styles/tokens.override.css` | Brand overrides — team-owned |
| `src/shared/ui/` | Interface kit copied into the repository — team-owned |
| `docs/adr/` | Architecture decision records — team-owned |
| `.scaffold/manifest.json` | Generated files and their hashes |

## Updating generated files

Edit `scaffold.yaml`, then run `prepwork sync`. A generated file the team has modified is reported, never overwritten.
